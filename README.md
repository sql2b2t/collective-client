# Collective Client

Collective client - клиент разработанный для сервера 2b2t.org.ru И других серверов с гримом, имеет систему скриптов на котлине и аддонов на джаве.

## Скачать
Последний релиз: https://github.com/sql2b2t/collective-client/releases/latest

## Сборка из исходников
```bash
./gradlew build -x test
# готовый мод: build/libs/collective-1.21.11-1.3.9.jar
```
Требуется JDK 21.
